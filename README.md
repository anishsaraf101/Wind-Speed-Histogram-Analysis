# Project Name: Augspurger Data Analysis

## Description
The project analyzes windspeed data from a dataset by implementing algorithms in Java to extract meaningful insights. It processes the data by reading it from a CSV file, calculating basic statistics, and identifying trends over time. The program groups windspeed data into bins, which enables data vizualization. 

The system also allows for filtering and summarizing the data based on user-given conditions, like the times or thresholds. This gives the user easy access to the specific data they like to analyze.

## Files
1. **Augspurger_2017_10.csv**: The windspeed dataset used for analysis.
2. **AugspurgerData.java**: A Java class for managing and analyzing the Augspurger dataset.
3. **Bin.java**: A supporting Java class used in the data analysis process to make the histogram.
